Help & Controls

Keyboard

Move: AD / arrows
Jump: Space / K (hold = higher)

Fire: J / X (hold W to aim up)
Pause / back: Esc

Gamepad

Move: stick / d-pad
Jump: A / B
Fire: X / Y / bumpers / RT
Pause: Start
Menus: d-pad + A

Touch
